# Lean Startup - Build > Measure > Learn
https://www.youtube.com/watch?v=RSaIOCHbuYw

Loop:
1. Build
2. Measure
3. Learn

Takeaways:
1. Planning works backwards
  - Plan what we want to learn
  - Formulate Hypothesis
  - Validate or reject them
2. Everything is a grand experiment
  - Observe don't ask
  - Create a Landing Page or MVP and observe results
  - Waste: Everythoing that does not lead to validated learning
  - (waste in Toyota Lean Manuf: Everythong that does not create value for the customer)
  - MVP should contain bare minimum to aprove or reject hypothesis
3. Different types of MVPs
  - The Video MVP + Signup of product
  - Concierge MVP > focus on single or very few customers
  - Wizard of Oz > Pretend that you have developed a fancy tech solution while behind the curtains it is operated by humans (and measure results and find out if the concept works)
4. The three engines of growths
  - Sticky engine > customers come and should stay for a long time
    * kpi: customer acquistion rate
    * kpi: churn rate
  - Viral Engine
